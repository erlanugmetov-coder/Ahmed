# Закуп и смены

Сайт для точек Love Food, Bon Jour (Almaty Mall) и FixBite (Asia Park): закуп, остатки, отметки прихода и ухода, табель с часами и суммами.

- `index.html` — сайт (GitHub Pages).
- `apps-script/Code.gs` — связка с Google Таблицей.

## Подключение Google Таблицы (один раз, ~15 минут, на компьютере)

1. Открой **sheets.google.com**, создай пустую таблицу и назови её «Смены и закуп».
2. В меню выбери **Расширения → Apps Script**.
3. Сотри всё в окне кода и вставь весь текст из файла `apps-script/Code.gs`. Нажми 💾 «Сохранить».
4. Вверху в списке функций выбери **setup** и нажми **▶ Выполнить**. Google попросит разрешение: «Проверить разрешения» → выбери свой аккаунт → «Дополнительно» → «Перейти в проект (небезопасно)» → «Разрешить». Это твой собственный скрипт, так и должно быть.
5. Вернись в таблицу: появятся листы «Отметки», «Списки», «Ставки», «Настройки».
6. На листе **«Настройки»** замени PIN `1234` на свой.
7. В Apps Script нажми **Начать развертывание → Новое развертывание**. Шестерёнка → **Веб-приложение**.
   - «Запуск от имени»: **Я**
   - «У кого есть доступ»: **Все**
   - Нажми **Развернуть** и скопируй **URL веб-приложения** (начинается с `https://script.google.com/macros/s/…/exec`).
8. Пришли этот адрес Claude, и он вставит его в сайт. Или сам: в `index.html` найди строку `const API = "";` и вставь адрес в кавычки.

Проверка: открой адрес веб-приложения в браузере, должно показаться `{"ok":true,"msg":"Связка работает"}`.

## Если поменял код скрипта

Начать развертывание → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть. Адрес останется тем же.

## Как пользоваться

- **Сотрудники:** вкладка «Смена» → имя → «Пришёл» / «Ушёл». Отметка пишется в таблицу и уходит сообщением в WhatsApp-группу.
- **Руководитель:** вкладка «Табель» → PIN → часы, смены и суммы за месяц, кнопка «Скачать Excel». Ставку можно вписать прямо в табеле.
- Время берётся с сервера Google в момент нажатия, поменять его на телефоне нельзя.
- Если сотрудник забыл отметить уход, день попадает в список «Проверь вручную» и в часы не входит.
